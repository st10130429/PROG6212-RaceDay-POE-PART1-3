 RaceDay – Part 1: System Planning and Database

RaceDay is a full-stack web-based event management system for the South
African road running, walking, and cycling community. It allows Event
Organisers to create and manage events, categories, and participant
results, while Participants can browse events, enrol in categories,
track their enrolments and results, and view route information to
prepare for race day.

Roles

Organiser– can create, edit, and delete their own events, manage
event categories, capture participant results, and view all enrolments
for their events.

**Participant** – can create an account, browse events, enrol in a
category, view their own enrolments, and track their personal results
and route information.

Role-based access will be enforced at the API level in Part 2 and
reflected consistently in the MVC interface in Part 3.
